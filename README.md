# Customer Churn Prediction 📉

A machine learning project to predict whether a customer is likely to churn based on historical usage and service data.

# Problem Statement
Customer churn leads to revenue loss. This project helps identify high-risk customers early so businesses can take preventive actions.

# Tools & Techniques Used
- Python  
- Pandas, NumPy (data preprocessing & analysis)  
- Scikit-learn  
- Logistic Regression  
- Train-test split & model evaluation  

# Key Outcomes
- Built a classification model to predict churn  
- Identified important features influencing customer retention  
- Achieved reliable prediction performance on unseen data  

# Skills Gained
- Data preprocessing and feature selection  
- Binary classification modeling  
- Model evaluation and interpretation
